# NuGet: вариант 23, этап 3

Python 3.10+, стандартная библиотека. Сборка и установка Python-пакетов не нужны.
Для защиты каждый этап находится в отдельном коммите.

## Файлы программы

- `run.py` — вход в программу.
- `src/cli.py` — запуск анализа, обработка ошибок и ввод команд.
- `src/config.py` — параметры и их проверка.
- `src/versions.py` — работа с номерами версий.
- `src/nuget.py` — HTTP-запросы к NuGet и разбор nuspec через XML.
- `src/graph.py` — тестовый JSON и рекурсивный BFS.

## Запуск и параметры

```powershell
python run.py --package A --version 1.0.0 --repository demo/repository.json --test-mode
python -m unittest discover -s tests -v
```

Для настоящего NuGet укажите имя, нужную версию и
`--repository https://api.nuget.org/v3/index.json` без `--test-mode`.
`--package`, `--version`, `--repository` обязательны.
`--test-mode` выбирает файл вместо URL. `--output` задаёт PNG (по умолчанию `graph.png`).
`--ascii` включает текстовое дерево на этапе 5. Эти флаги не принимают значения.
Выходная папка должна существовать; неправильные настройки дают ошибку, код завершения 2.

Без аргументов `python run.py` открывает ручной ввод. Команды:
`analyze <те же параметры>`, `help`, `exit` (только вручную).
Пути с пробелами заключайте в кавычки и используйте прямой слеш `C:/My Files/file.json`.

## Демонстрация

```powershell
.\demo\demo.bat
```

Батник напрямую запускает Python и подаёт команды из `demo/commands.txt`.
После примеров программа остаётся для ручного ввода. Автоматического `exit` нет.
Ошибки не прерывают демонстрацию.

## Обход и тестовый файл

`demo/repository.json` — объект вида `{"A": ["B", "C"], "B": [], "C": []}`.
Все тестовые пакеты имеют условную версию 1.0.0, имена состоят из A-Z.
Файл содержит ромб A→B,C→D, цикл E↔F, петлю G→G и изолированный Z.
Ссылки на отсутствующие пакеты и неправильный JSON считаются ошибками.

Узел настоящего графа — пара `(имя, версия)`. `visit` обрабатывает весь текущий
уровень, затем рекурсивно вызывает себя для следующего: это BFS, а не DFS.
Множество `seen` не позволяет повторно раскрыть циклы и общих потомков.
При превышении лимита рекурсии Python выводится ошибка вместо бесконечного обхода.

Для зависимости выбирается минимальная подходящая версия: `1.0` — минимум,
`[1.0]` — точная версия, `[1,2)` — интервал с исключённой верхней границей.
Корень всегда берётся строго указанной версии. Ответы HTTP кешируются в памяти.
Все группы платформ объединяются; разные версии одного пакета остаются разными узлами.
Это обзор зависимостей всех платформ, а не полное восстановление .NET-проекта.
